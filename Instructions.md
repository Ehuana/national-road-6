# National Road 6 (1962) - Game Overview

- Setting: September 1962 (Monsoon Season), Cambodia (Phnom Penh -> Siem Reap / Angkor Wat).
- Tech: Vanilla JS, Tailwind CSS (CDN), VT323 Monospace font.
- Route: 310 km along National Road 6.
- Key Mechanics: Daily turn loop, food/fuel depletion, state machine inputs (1-3), random historical events.
